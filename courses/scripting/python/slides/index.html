A for loop visits each item in turn. An accumulator is a variable you update every pass.

Start the accumulator before the loop: 0 for a sum or count, 1 for a product, an empty list to collect.

% gives the remainder. n % 2 == 0 means n is even.

A list holds items in order. You can sort it, filter it, and build a new one from an old one.

Bigger problems are small problems stacked: a loop inside a loop, a check inside a loop.

find_primes needs two ideas you already have: a loop over candidates, and an inner check for divisors.

Write the inner check as its own helper function first. Test it alone. Then use it in the loop.

This is the shape of every Codewars kata that follows: break it down, test each piece.

1def is_prime(n):
2    if n < 2:
3        return False
4    for d in range(2, n):
5        if n % d == 0:
6            return False
7    return True
8 
9def find_primes(n):
10    return [p for p in range(2, n + 1) if is_prime(p)]
